# Lilac documentation site outline

This is the page plan for the public documentation site at `theme_documentation_url`. The Theme Store requires documentation that covers every feature and setting a merchant can use.

The content comes from [merchant-setup-guide.md](merchant-setup-guide.md). Each line below is one page; the guide section it draws on is in brackets.

**Before submission:** replace the placeholder `theme_documentation_url` and `theme_support_url` (`https://example.com/...`) in `config/settings_schema.json` with the live documentation and support URLs.
